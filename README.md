# Skill Pulse

**Skill Pulse** is a TypeScript web application for tracking, visualizing, and analyzing skill development.

## Features

- Organize and monitor skill progress
- Interactive, responsive interface
- Visual progress reporting
- Modern web-based dashboard

## Tech Stack

- **CSS:** 50.1%
- **TypeScript:** 46.7%
- **JavaScript:** 2%
- **HTML:** 1.2%

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm or yarn

### Installation

```bash
git clone https://github.com/ng29012008-code/skill-pulse.git
cd skill-pulse
npm install
```

### Run Locally

```bash
npm run dev
```

Open the local URL displayed by the development server.

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
